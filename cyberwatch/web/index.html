Detection contract

The detector uses flow statistics and protocol attributes. Labels, attack categories, addresses, record identifiers and split names are excluded from its inputs.

One contract. Two execution paths.

The local reference demonstrates the workflow. The distributed path uses the actual Big Data engines.

LOCAL REFERENCE

CSV / synthetic JSONL

Python ingestion → validation & detection → SQLite → dashboard

Runs without Docker. It does not emulate Kafka, Spark or Iceberg.
DISTRIBUTED LAKEHOUSE

Historical CSV replay

Kafka → Spark Structured Streaming → Iceberg on S3 → Trino → dashboard

Bronze: original payload · Silver: validated & scored flows · Gold: analytics marts.

Reliable replay

Stable event IDs support deduplication. Spark checkpoints track offsets. Per-table MERGE operations are retry-safe; the pipeline does not claim a cross-table exactly-once transaction.

Honest time semantics

Train/test CSVs do not contain original timestamps or addresses. Their replay times are simulated; addresses remain unavailable. Alerts apply to completed flow records.
